description: Draft a commit message for staged changes into GIT-COMMIT.msg
---

Create a git commit message for the only STAGED changes in the working directory. Explain WHY this change is needed (business reason, bug fix, or feature). Do not describe what code changed; that is visible in the diff.

First, review 5–10 recent commits to identify the team's commit-message style (tense, format, and length). Inspect the staged diff and write the commit message to `GIT-COMMIT.msg`. Do not run `git commit` or stage/unstage files.

Keep the message under 500 characters. Use technical writing principles and Simplified Technical English.
